# Ask Atlas: advisors’ own words

## What it changes
- **Ask Atlas:** these requests now open the right workspace instead of a generic answer:
  - "go fee-based" or "wrap account" → Conversion map;
  - "on-model" or "off-model" → CIO Model Fit;
  - "wash sale" or "which lots" → Tax personalization.
- With a model connected, the same phrases are given to the model as routing hints.

## Why
The product team hears in user research how advisors actually talk. Adding phrasing is a product decision that should not wait for an engineering release.

## Source
Atlas user research, advisor interviews (illustrative).
