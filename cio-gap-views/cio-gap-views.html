2 · Where the return gap comes from

Start from the model’s expected return; each tilt adds or takes away return; the steps land exactly on today’s holdings. The scale is zoomed to the gap.

Step = (holding weight − model weight) × (class expected return − model expected return). Because the weights differ by zero in total, the steps sum exactly to the gap. Risk does not add up this way, so it is shown in view 4.
